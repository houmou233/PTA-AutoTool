# PTA-AutoTool

PTA（拼题A）AI辅助答题油猴脚本。

## 功能

- 支持 DeepSeek、豆包、通义千问等多种AI模型
- 可拖拽浮动面板，支持边缘吸附
- 打字机模式：AI生成答案后不自动写入，用户逐字按键输入，模拟真人操作
- ESC快捷键收起/展开面板
- 面板默认收起，不挡视线
- 紧凑代码排版，模拟真人手写风格

## 安装

1. 安装 [ScriptCat](https://scriptcat.org/) 或 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 点击下面的安装按钮：

[![Install](https://img.shields.io/badge/Install-UserScript-brightgreen)](https://raw.githubusercontent.com/houmou233/PTA-AutoTool/main/PTA-AutoTool.user.js)

或手动复制 `PTA-AutoTool.user.js` 内容到油猴脚本管理器中新建脚本。

## 使用

1. 进入 PTA 编程题页面
2. 点击右下角问号图标展开面板
3. 选择AI模型，填入API Key
4. （可选）开启「打字机模式」
5. 点击「开始解题」
